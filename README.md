# Integration Barriers in Open-Source SSI Frameworks: Replication Package

This repository contains the replication package and dataset for our double-anonymous submission to the SBES 2026 Insightful Ideas and Emerging Results Track.

## Contents
1. **`Integration_Friction_Assessment_Instrument.pdf`**: The blank questionnaire used during the exploratory probe, detailing the task instructions and evaluation scales.
2. **`Anonymized_Participant_Responses.csv`**: The raw dataset containing task-level friction scores (1 to 5) and transcribed qualitative feedback from all 9 early integrators. All personally identifiable information has been scrubbed to protect participant privacy and maintain double-anonymous review compliance.

## Usage
These artifacts are provided for peer-review purposes. Upon acceptance of the paper, this repository will be migrated to a permanent public URL with open-source licensing.
